Neon Bay is an open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun. A sun-soaked coastal city to explore on foot and by car, with traffic and pedestrians, cars to steal, a five-star wanted level with police who respond, a five-mission story chain for the fixer Mara Voss, taxi jobs after the story, combat, a HUD with a live minimap, and a save in the browser. Plain static files, no libraries, no network requests.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. Or open `game/index.html` directly.

## Play

WASD move / drive · Shift run · E enter or leave a car · Mouse aim, Click shoot · P pause · M mute · Enter start · C continue a saved game.
